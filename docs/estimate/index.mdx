> ステータス: **draft**

このセクションでは、[要件定義](/requirements)と[設計](/design)に基づく費用を提示します。

## 構成

| ドキュメント | 内容 |
| --- | --- |
| [開発費用](/estimate/development-cost) | WBS ベースの工数見積もり(人日 × 単価) |
| [運用費用](/estimate/operation-cost) | 月額ランニングコスト・保守費用・年間総額 |

## 書き方ガイド

1. 見積もりは必ず **要件定義・設計が固まってから** 作成・更新します
2. WBS の各タスクには対応する要件 ID(FR-xxx / NFR-xxx)を紐付けます
3. **前提条件と除外事項を必ず明記** します(スコープ外作業のトラブル防止)
4. リスクバッファは根拠とともに計上します

:::warning
上流ドキュメント(要件・設計)を変更したら、必ず見積もりへの影響を確認し、ステータス行を `draft` に戻して再見積もりしてください。
:::

:::tip
Claude Code で `/estimate` スキルを実行すると、要件・設計を読み込んだうえで `estimator` サブエージェントが工数を算出します。
:::
