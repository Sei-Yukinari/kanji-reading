## リスクバッファ

全体の **10%(¥957,000)** を計上する。主な不確実性と工数の振れ幅は以下のとおり。全体の振れ幅は約 155〜215 人日(−10% / +25%)で、上振れの大半はコンテンツ工程にあるため、後述の段階見積もり条件で補う。

| リスク | 振れ幅(人日) | バッファ根拠・対応 |
| --- | --- | --- |
| 人手チェックの速度(1.5 分 / 1 分は実測なし) | −7 / +13 | 1 年生分の実測で再見積もり(前提条件参照) |
| 生成 AI 下書きの書き直し率(20% 想定、10〜40% の幅) | −4 / +8 | 同上 |
| 問題数の増加(読みの多い漢字で 1 字 5 問を超える) | 0 / +6 | 同上 |
| 音訓割り振り表の入手形式(PDF のみの場合は手入力) | −2 / +3 | 着手 1 週目に確認 |
| 音声本数・アクセント誤り率 | −1 / +3 | バッファで吸収 |
| Serwist が static export で動かない(T-002) | 0 / +3 | 技術検証で早期判断。バッファで吸収 |
| 仮置きパラメータの変更(タイムアタック・メダル・習得基準) | 0 / +3 | 設計レビューまでに確定。以降の変更は仕様変更扱い |

## 前提条件

- 本見積もりは 2026/10/04 時点の要件定義書・設計書(いずれも draft)に基づく概算である
- **段階見積もり条件**: 1 年生分の問題データ制作(1 回目チェックまで)を終えた時点で、実測値をもとにフェーズ3 の工数を再見積もりする。差異が ±10% を超える場合は金額を協議する
- 技術選定の推奨案(T-001〜T-003, T-005, T-008〜T-010)が承認されること
- 仮置きパラメータ(1 セット 10 問・単元 約 20 字・タイムアタックのルール・習得基準・プロフィール上限 4 件)で実装し、設計レビュー完了までに確定すること
- 特別な読み(熟字訓・当て字)は出題対象外とする(対象に含める場合は約 +3.5 人日)
- 単元の並び順は学年別漢字配当表の掲載順とする
- メダルは 8 種類程度([機能設計](/design/functional-spec)の仮置き一覧)とし、画像はデザイナーが作成する(外部イラストレーターへの発注なし)
- VOICEVOX のキャラクターは商用利用・クレジット表記のみで利用できるものを選び、顧客がクレジット表記に同意すること
- 問題データの正確性は自社の 2 回の人手チェックで担保する(外部監修なし)
- 検証用の実機(iPad・iPhone・Android・Chromebook・Windows PC)は自社保有または顧客貸与とする
- 顧客レビューは提示から 5 営業日以内に完了すること
- コンテンツ担当 2 名を 2〜11 週に確保できること
