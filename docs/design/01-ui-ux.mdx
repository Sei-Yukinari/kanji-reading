## デザイン方針

### 基本方針

- 主要ユーザーは小学 1〜6 年生。**1 画面 1 タスク・1 タップ 1 アクション**で、迷わずテンポよく進める構成とする(NFR-006)
- ビジュアルはリポジトリ直下の `DESIGN.md`(getdesign.md の Apple スタイル分析)に準拠する。「プロダクト写真を主役に UI を引っ込める」思想を、本アプリでは **出題中の漢字を主役** に置き換えて適用する
- 文言はひらがな中心・短文。漢字を使う場合はルビを付ける(NFR-007, FR-022)
- アプリ起動から 3 タップ以内で出題を開始する(NFR-006)
  - 起動 → 前回のプロフィール・学年で SCR-003 ホームを表示 → 「れんしゅう」(1) → 単元(2) → 出題開始

### DESIGN.md の適用と子ども向けの調整

DESIGN.md をそのまま適用すると子ども向けの要件を満たせない箇所は、以下のとおり調整する。調整箇所以外は DESIGN.md のトークンを正とする。

| 項目 | DESIGN.md の規定 | 本アプリでの扱い | 理由・根拠要件 |
| --- | --- | --- | --- |
| アクセントカラー | Action Blue `#0066cc` の 1 色のみ | 操作要素は Action Blue のみとする。例外として **正解(緑)・不正解(赤)のフィードバック色** を追加する | 正誤を一目で伝えるため。色だけに頼らず ⭕️/❌ 記号を必ず併用する(NFR-008) |
| 書体(欧文) | SF Pro(system-ui) | `system-ui, -apple-system` を先頭にしたスタックを踏襲 | — |
| 書体(和文) | 規定なし | UI 文言: OS 標準の日本語ゴシック(ヒラギノ角ゴ / Noto Sans JP)。**出題漢字・熟語・例文: 教科書体系の書体** | 学校で習う字形(とめ・はね・はらい)と表示を一致させるため。書体は技術選定 T-007 で決定 |
| 本文サイズ | 17px | 本文 17px 以上は踏襲。ボタン文言は 20px 以上、出題漢字は単漢字 120px 以上・熟語 80px 以上 | 低学年の可読性(NFR-007) |
| letter-spacing | 見出しで負のトラッキング | 和文には適用しない(0) | 和文に負のトラッキングを掛けると詰まって読みにくい |
| 影 | 製品写真のみ 1 種類 | メダルのイラストにのみ適用(Product shadow) | メダルを「ごほうびの実物」として見せる |
| ダークモード | 規定はライト中心 | 既定はライト。SCR-009 設定の「くらい がめん」で ON にしたときだけダーク配色にする(OS の外観設定には追従しない) | 夜間・暗所での学習時のまぶしさを抑える(FR-024)。既定をライトに固定し、端末によって見た目が変わらないようにする。値は DESIGN.md の `primary-on-dark` と iOS のダーク配色に合わせる |
| 装飾 | グラデーション・装飾なし | 踏襲。キャラクター・イラストは使わない(メダル画像を除く) | 顧客回答(デザイン制約なし・新規作成)と DESIGN.md の思想に合わせる |

- feedback 色は白背景でコントラスト比 4.5:1 以上を満たす値とする
- ダーク配色でも文字色(ink / ink-muted / primary / feedback)は canvas 背景に対してコントラスト比 4.5:1 以上とする。primary-fill はダークでは文字用より暗い `#0071e3` とし、白文字とのコントラスト比 4.5:1 以上を確保する

### SCR-003: ホーム

- 上部: プロフィールのアイコン・ニックネーム(タップで SCR-001)、設定ボタン(44px 円形)
- 学年切替: 「1ねん」〜「6ねん」のピル型セグメント(前回の選択を保持)
- モードボタン: 大きなカード 3 枚を縦に並べる(れんしゅう / タイムアタック / ふくしゅう)
  - ふくしゅう: 復習対象の問題数をバッジ表示。0 件の場合は無効表示
- 下部: 「おぼえた かんじ」(SCR-007)・「メダル」(SCR-008)への入口
- 初回のみ、ホーム画面追加の案内(SCR-010)をバナーで表示

### SCR-005: 出題

![SCR-005: 出題](/diagrams/design-01-ui-ux-01.svg)

- ヘッダー: 「やめる」ボタン、進捗(例: 3/10 のドット表示)、タイムアタック時は経過時間
- 問題エリア
  - 単漢字: 漢字 1 字を 120px 以上で表示。送り仮名がある場合は送り仮名をひらがなで添える(例: 上**る**)
  - 熟語: 熟語を 80px 以上で表示
  - 文中: 例文を表示し、出題漢字に下線と強調。出題対象以外の漢字はルビ付き
  - 読み上げボタン(🔈、44px 円形)
- 選択肢: 2x2 グリッド(横向き時は漢字の右に 2x2)。1 ボタンは高さ 72px 以上、文字 24px 以上、角丸 18px(`rounded.lg`)、白地 + hairline 枠
- 回答後: 押した選択肢と正解の選択肢を枠色 + ⭕️/❌ で示し、問題エリアに正しい読みを表示する。他の選択肢は無効化する

### SCR-006: 結果

- 正答数を大きく表示(例: 「8 / 10 もん せいかい!」)
- タイムアタック時: タイムと自己ベスト。更新時は「じこベスト こうしん!」を強調
- 間違えた問題: 漢字と正しい読みのリスト(タップで読み上げ)
- 獲得メダル: 新たに獲得したメダルをアニメーション付きで表示
- ボタン: 「もういちど」(primary)、「ホームへ」(secondary)

### SCR-007: 習得状況

- 学年の漢字をグリッド表示(1 マス 56px 以上)
- 状態: 未学習(グレー文字)・学習中(ink)・習得済み(primary 背景・白文字 + ✓)
- 学年全体と単元ごとの習得率

## 共通UIルール

- **ボタン**: 主要操作は primary のピル型(`rounded.pill`)、カード型の選択は `rounded.lg`。押下時は `transform: scale(0.95)`(DESIGN.md のマイクロインタラクション)
- **タップ領域**: すべての操作要素は 44 × 44px 以上。出題画面の選択肢は 72px 以上の高さ(NFR-005)
- **連打防止**: 選択肢は最初の 1 タップのみ受け付け、正誤表示中は無効化する
- **確認ダイアログ**: 「やめる」(出題の中断)とプロフィール削除のみ。それ以外の操作で確認を挟まない
- **文言**: ひらがな中心、1 文 20 文字程度まで。漢字を使う場合はルビを付ける
- **アニメーション**: 画面遷移は 200ms 以内のフェード。OS の「視差効果を減らす」設定時はアニメーションを無効化する
- **音**: 効果音・読み上げは設定で OFF にできる。音が OFF でも学習が成立する表示にする(NFR-008)
- **日時表示**: 記録の日付は `YYYY/MM/DD`、タイムは `12.3びょう`
