## 遷移条件

| 遷移元 | 遷移先 | トリガー・条件 | 備考 |
| --- | --- | --- | --- |
| 起動 | SCR-002 | 端末内にプロフィールが 0 件(iOS / iPadOS の Safari タブ起動を除く) | 初回起動 |
| 起動 | SCR-010 | プロフィールが 0 件、かつ iOS / iPadOS の Safari タブで起動(ホーム画面アプリではない) | Safari タブとホーム画面アプリでストレージが分離されるため、プロフィール作成前に案内する |
| SCR-010 | SCR-002 | 「あとで」押下 | ホーム画面に追加して起動し直した場合は、起動フローからやり直す(プロフィール 0 件 → SCR-002) |
| 起動 | SCR-003 | プロフィールが 1 件、または前回選択したプロフィールが存在する | 前回の学年を復元 |
| 起動 | SCR-001 | プロフィールが 2 件以上で、前回選択が存在しない(削除済み等) | — |
| SCR-002 | SCR-003 | 「はじめる」/「ほぞん」押下 | ニックネーム 1〜10 文字 |
| SCR-001 | SCR-003 | プロフィールをタップ | — |
| SCR-001 | SCR-002 | 「ついか」押下 | 上限数に達している場合は非表示 |
| SCR-003 | SCR-004 | 「れんしゅう」押下 | — |
| SCR-004 | SCR-005 | 単元をタップ | 押下後すぐに 1 問目を表示 |
| SCR-003 | SCR-005 | 「タイムアタック」押下 | 3 秒のカウントダウン後に開始 |
| SCR-003 | SCR-005 | 「ふくしゅう」押下 | 復習対象が 1 件以上の場合のみ有効 |
| SCR-005 | SCR-006 | 最終問題の正誤表示の終了後 | 自動遷移 |
| SCR-005 | SCR-003 | 「やめる」押下 → 確認で「やめる」 | 途中結果は保存しない |
| SCR-006 | SCR-005 | 「もういちど」押下 | 同じモード・学年・単元で新しいセットを生成 |
| SCR-006 | SCR-003 | 「ホームへ」押下 | — |
| SCR-003 | SCR-010 | 初回起動時、かつ PWA としてインストールされていない場合 | バナーをタップで表示。閉じたら再表示しない |
| SCR-009 | SCR-010 | 「ホームがめんに ついか」押下 | — |
| SCR-009 | SCR-002 | プロフィールの編集を押下 | — |

## 例外時の遷移

- 出題中にアプリがバックグラウンドへ移行した場合: タイムアタックは計測を一時停止し、復帰時に「つづける / やめる」を表示する。れんしゅう・ふくしゅうはそのまま継続する
- 出題中にページを再読み込み・アプリを再起動した場合: 中断扱いとし SCR-003 から再開する(途中結果は保存しない)
- 問題データのキャッシュが未完了で、かつオフラインの場合: 未取得の学年を選択不可とし、「インターネットに つないでね」と表示する
- 端末内ストレージの読み書きに失敗した場合: SCR-003 にエラーバナーを表示し、学習は継続できるが記録が保存されない旨を伝える
- 存在しない URL へのアクセス: SCR-003 へリダイレクトする
