### API-001: 例: 受注登録

#### リクエスト

| 項目 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| customerId | bigint | ○ | 顧客ID |
| orderedAt | date | ○ | 受注日 |
| items | 配列 | ○ | 受注明細 |

#### レスポンス

| フィールド | 型 | 説明 |
| --- | --- | --- |
| id | bigint | 受注ID |
| orderNumber | string | 受注番号 |

#### エラーレスポンス

| HTTPステータス | 条件 | メッセージ |
| --- | --- | --- |
| 400 | 入力値不正 | バリデーションエラー内容 |
| 404 | 顧客が存在しない | 「顧客が見つかりません」 |
