[アーキテクチャ設計](/design/architecture)のコンポーネント設計を前提に、データモデルを図示します。詳細なカラム定義・制約は実装フェーズで別途作成します。

本アプリはサーバー側にデータベースを持たない。データは次の 2 種類に分かれる。

| 区分 | 保存場所 | 更新者 | 内容 |
| --- | --- | --- | --- |
| 問題データ(マスタ) | 静的 JSON ファイル(ビルド時に生成し CDN 配信、端末にキャッシュ) | 運営者(リリースで更新) | 学年・単元・漢字・読み・問題 |
| 学習データ | 端末内の IndexedDB | 学習者の操作 | プロフィール・設定・解答履歴・習得状況・記録・メダル |

## エンティティ一覧

### 問題データ

| エンティティ | 概要 | 主なリレーション | 対応要件 |
| --- | --- | --- | --- |
| GRADE | 学年(1〜6) | UNIT に分割される | FR-001 |
| UNIT | 学年内の単元(約 20 字ずつ) | KANJI を含む | FR-015 |
| KANJI | 学年別漢字配当表の漢字(1,026 字) | READING を持つ | FR-021 |
| READING | 小学校で扱う音訓(1 漢字に複数) | QUESTION の正解になる | FR-021, FR-014 |
| QUESTION | 4 択問題(熟語・文中の 2 形式)。誤答・ルビ・音声パスを含む | KANJI・READING に属する | FR-004〜FR-006, FR-009, FR-022 |

### 学習データ

| エンティティ | 概要 | 主なリレーション | 対応要件 |
| --- | --- | --- | --- |
| PROFILE | 学習者プロフィール(上限 4 件) | 全学習データの親 | FR-016, FR-017 |
| SETTINGS | 効果音・読み上げの設定 | PROFILE と 1 対 1 | FR-010 |
| SESSION | 1 セットの実施結果 | ANSWER を含む | FR-002, FR-011 |
| ANSWER | 1 問ごとの解答 | SESSION に属する | FR-007, FR-014 |
| READING_PROGRESS | 読みごとの連続正解数・習得状態。漢字の習得状況はここから算出 | PROFILE に属する | FR-014 |
| REVIEW_ITEM | 復習対象の問題 | PROFILE に属する | FR-013 |
| BEST_RECORD | タイムアタックの学年別自己ベスト | PROFILE に属する | FR-011 |
| MEDAL_AWARD | 獲得したメダル | PROFILE に属する | FR-012 |
| KUKU_PROGRESS | 九九の式(81 式)ごとの速い正解の連続数・習得状態 | PROFILE に属する | FR-026, FR-033 |
| KUKU_REVIEW | 九九の復習対象の式と、登録理由(誤答 / 遅い正解) | PROFILE に属する | FR-033 |
| KUKU_BEST | 九九のタイムアタックの自己ベスト(選んだ段の組み合わせごと) | PROFILE に属する | FR-011, FR-027 |

## 備考

- 問題データの ID は人が読める形式(漢字・読みを含む)とし、データ修正時に差分を追いやすくする。ID は一度公開したら変更しない(学習データが参照するため)
- 問題データを修正して問題を削除した場合、学習データ側の参照切れ(REVIEW_ITEM 等)は起動時に除去する
- 学習データのスキーマにはバージョン番号を持たせ、スキーマ変更時は起動時にマイグレーションする
- 「漢字の習得済み」は保存せず、READING_PROGRESS から算出する(漢字の全読みが mastered のとき習得済み)
- 連続学習日数は SESSION.finished_at から算出する
- ANSWER は端末容量を考慮し、プロフィールあたり直近 5,000 件を上限に古いものから削除する
