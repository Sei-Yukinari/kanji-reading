### 優先度の定義(MoSCoW)

| 優先度 | 意味 |
| --- | --- |
| Must | 必須。これがないとプロジェクトの目的を達成できない |
| Should | 重要。原則対応するが、納期・予算次第で調整可能 |
| Could | あれば望ましい。余力があれば対応 |
| Won't | 今回は対応しない(スコープ外として記録) |

### 今回対応しない要求(Won't)

- 漢字の書き取り・書き順の練習
- 保護者による学習状況の閲覧
- 学校・教室単位での導入・管理
- 端末をまたいだ学習記録の引き継ぎ
- 課金・広告
- ネイティブアプリ(iOS / Android)の開発・ストア配信
- 中学校以降で習う漢字・読みの出題
- 外部有識者(教員等)による問題データの監修
- 利用統計の収集(REQ-017)

## 受け入れ基準

### REQ-001 の受け入れ基準

- 1〜6 年の学年を選択でき、選択した学年に配当された漢字のみが出題される

### REQ-002 の受け入れ基準

- 学年別漢字配当表の全 1,026 字が、いずれかの問題の出題対象になっている
- 各漢字について、小学校で扱う読み(音読み・訓読み)がすべて、いずれかの問題の正解になっている
- 問題データの読みに誤りがない(全件の人手チェック済み)

### REQ-003 の受け入れ基準

- 1 問の回答は選択肢を 1 回タップするだけで完了する
- 選択肢は 4 つで、タブレット・スマートフォンで押し間違えない大きさで表示される

### REQ-004 の受け入れ基準

- 回答直後に正誤が表示され、ボタン操作なしで次の問題に進む
- 1 セットの問題数が固定で、最後の問題の後に結果が表示される
- アプリ起動から 3 タップ以内で問題が始まる

### REQ-005 の受け入れ基準

- 単漢字の読み・熟語の読み・文中の読みの 3 形式の問題が、全学年で出題される

### REQ-006 の受け入れ基準

- 正解・不正解で異なる効果音が鳴る
- 正しい読みを音声で再生できる
- 効果音・読み上げはそれぞれ ON/OFF できる

### REQ-007 の受け入れ基準

- タイムアタックモードで、所要時間(または制限時間内の正答数)が表示・記録される
- 自己ベストが記録され、更新時に知らされる

### REQ-008 の受け入れ基準

- 満点・連続学習日数などの条件を満たすとメダル・スタンプが獲得でき、獲得済みのものを一覧で見られる

### REQ-013 の受け入れ基準

- 初回アクセス時に、登録・ログインなしで学習を開始できる
- 氏名・メールアドレス等の個人情報を入力させない

### REQ-014 の受け入れ基準

- 一度アクセス(またはホーム画面に追加)した後は、通信がない状態でも全学年の学習ができる

### REQ-015 の受け入れ基準

- iPad・iPhone・Android スマートフォン・Chromebook・Windows PC の主要ブラウザで、縦横どちらの向きでも操作できる

### REQ-016 の受け入れ基準

- 出題対象以外の漢字は、ひらがなまたはルビ付きで表示される
- 選択肢はすべてひらがなで表示される
