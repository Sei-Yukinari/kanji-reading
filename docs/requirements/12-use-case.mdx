システムに対する利用者(アクター)の操作単位を定義します。各ユースケースは[要求定義](/requirements/user-requirements)の REQ に紐付け、[画面一覧](/design/ui-ux)・テスト設計の入力にします。

## アクター一覧

| アクター | 説明 |
| --- | --- |
| 学習者 | 小学 1〜6 年生。アプリで漢字の読みを練習する |
| 保護者 | 端末を用意し、初回のホーム画面追加・プロフィール作成を手伝う |
| 運営者 | 自社(または顧客)の運営担当。問題データの更新を行う |

## ユースケース一覧

| ID | ユースケース | アクター | 概要 | 対応要求 |
| --- | --- | --- | --- | --- |
| UC-001 | 学年・単元を選んで練習する | 学習者 | 学年と単元を選び、1 セットの 4 択問題を解いて結果を見る | REQ-001, REQ-003, REQ-004, REQ-005, REQ-006, REQ-011, REQ-016 |
| UC-002 | タイムアタックに挑戦する | 学習者 | 学年を選び、所要時間を競って自己ベストを更新する | REQ-007 |
| UC-003 | 間違えた問題を復習する | 学習者 | 過去に間違えた問題のみを解き直す | REQ-009 |
| UC-004 | 習得状況・メダルを確認する | 学習者 | 漢字ごとの習得状況と獲得メダルを一覧で見る | REQ-008, REQ-010 |
| UC-005 | プロフィールを作成・切り替える | 学習者, 保護者 | ニックネームでプロフィールを作り、兄弟で切り替えて使う | REQ-012, REQ-013 |
| UC-006 | ホーム画面に追加してオフラインで使う | 保護者 | ブラウザでアクセスしホーム画面に追加。以降は通信なしで利用 | REQ-014, REQ-015 |
| UC-007 | 効果音・読み上げを設定する | 学習者, 保護者 | 効果音・音声読み上げの ON/OFF を切り替える | REQ-006 |
| UC-008 | (対象外)利用統計を確認する | 運営者 | REQ-017 が Won't となったため対象外。ID は欠番として保持 | REQ-017 |
| UC-009 | 問題データを更新・公開する | 運営者 | 問題データの誤りを修正し、アプリに反映する | REQ-002 |

## ユースケース記述

### UC-001: 学年・単元を選んで練習する

| 項目 | 内容 |
| --- | --- |
| アクター | 学習者 |
| 事前条件 | プロフィールが選択されていること |
| 事後条件 | 解答結果が端末内に保存され、習得状況・メダルが更新されていること |
| トリガー | 学習者がホーム画面で「れんしゅう」を選んだとき |

### UC-002: タイムアタックに挑戦する

| 項目 | 内容 |
| --- | --- |
| アクター | 学習者 |
| 事前条件 | プロフィールが選択されていること |
| 事後条件 | 記録が保存され、自己ベストを更新した場合は自己ベストが更新されていること |
| トリガー | 学習者がホーム画面で「タイムアタック」を選んだとき |

### UC-006: ホーム画面に追加してオフラインで使う

| 項目 | 内容 |
| --- | --- |
| アクター | 保護者 |
| 事前条件 | 端末がインターネットに接続されていること(初回のみ) |
| 事後条件 | アプリ本体・全問題データ・音声が端末にキャッシュされ、オフラインで起動できること |
| トリガー | 保護者がアプリの URL にアクセスしたとき |
