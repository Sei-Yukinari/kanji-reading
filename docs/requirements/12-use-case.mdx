### UC-001: 例: 入出庫を記録する

| 項目 | 内容 |
| --- | --- |
| アクター | 例: 在庫管理担当 |
| 事前条件 | 例: 対象商品がマスタに登録済みであること |
| 事後条件 | 例: 在庫数が更新され、履歴が記録されていること |
| トリガー | 例: 商品の入荷・出荷が発生したとき |

#### フロー

{/* TODO: 基本フローを時系列で描き、代替フローは alt、例外フローは opt で表現する */}

```mermaid
sequenceDiagram
    actor A as 在庫管理担当
    participant S as 在庫管理システム
    A->>S: 商品を検索(またはバーコードをスキャン)
    alt 商品が見つからない場合(代替フロー)
        S-->>A: 新規登録画面を表示
        A->>S: 商品を新規登録
    end
    S-->>A: 商品情報と現在庫数を表示
    A->>S: 入庫/出庫の区分と数量を入力
    opt 出庫数が在庫数を超える場合(例外フロー)
        S-->>A: 警告を表示し確認を求める
    end
    S->>S: 在庫数を更新
    S-->>A: 完了を表示
```
