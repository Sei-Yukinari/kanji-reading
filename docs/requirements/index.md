> ステータス: **draft**

このセクションでは、プロジェクトの前提と「何を作るか」を定義します。

## 構成

| ドキュメント | 内容 |
| --- | --- |
| [プロジェクト概要](/requirements/project-overview) | 背景・目的・スコープ・体制・スケジュール |
| [要求定義](/requirements/user-requirements) | 顧客の要求(REQ-xxx)の整理と優先度付け |
| [システム要件定義](/requirements/system-requirements) | 機能要件(FR-xxx)・非機能要件(NFR-xxx) |

## 書き方ガイド

1. **プロジェクト概要**から着手し、顧客との共通認識を先に固めます
2. **要求定義**では顧客の言葉のまま要求を収集し、REQ-xxx の ID を採番します
3. **要件定義**では要求をシステム要件へ翻訳し、各要件に対応する要求 ID を必ず記載します(トレーサビリティ)

:::tip
Claude Code で `/requirements` スキルを実行すると、ヒアリング形式でこのセクションを埋められます。
:::
