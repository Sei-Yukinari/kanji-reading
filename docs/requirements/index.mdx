## 書き方ガイド

1. **プロジェクト概要**から着手し、顧客との共通認識を先に固めます
2. **要求定義**では顧客の言葉のまま要求を収集し、REQ-xxx の ID を採番します
3. **要件定義**では要求をシステム要件へ翻訳し、各要件に対応する要求 ID を必ず記載します(トレーサビリティ)

:::tip
Claude Code で `/requirements` スキルを実行すると、ヒアリング形式でこのセクションを埋められます。
:::
