### 機能詳細

#### 学習の基本フロー

![学習の基本フロー](/diagrams/requirements-03-system-requirements-01.svg)

#### FR-003〜FR-005: 出題形式

| 形式 | 問題表示 | 正解の例 | 対応要件 |
| --- | --- | --- | --- |
| 単漢字の読み | 漢字 1 字 + 読みの種類のヒント(例: 「くんよみ」) | 「山」→ やま | FR-003 |
| 熟語の読み | 熟語 | 「火山」→ かざん | FR-004 |
| 文中の読み | 例文(出題対象の漢字に下線) | 「たかい【山】に のぼる」→ やま | FR-005 |

- 熟語・例文に含まれる出題対象以外の漢字は、その学年までに習う漢字に限るか、ひらがな/ルビ表示とする(FR-022)
- 単漢字の読みは、1 字に複数の読みがあるため、問題ごとに音読み・訓読みのどちらを問うかを明示する

#### FR-006: 選択肢

- 選択肢は 4 つ(正解 1・誤答 3)、すべてひらがな表記
- 誤答は「同じ漢字の別の読み」「形の似た漢字の読み」「音の似た読み」等から生成し、正解と同じ読みが紛れ込まないようにする
- 選択肢の並び順はランダム
- 詳細な誤答生成ルールは設計で定める

#### FR-007: 正誤表示と自動遷移

- 正誤は記号(⭕️/❌)と色を併用して表示する
- 不正解時は正しい選択肢を強調表示する
- 自動遷移までの時間は設計で定める(目安: 正解 約 1 秒、不正解 約 2 秒)

#### FR-021: 問題データ

| 学年 | 配当漢字数 |
| --- | --- |
| 1 年 | 80 字 |
| 2 年 | 160 字 |
| 3 年 | 200 字 |
| 4 年 | 202 字 |
| 5 年 | 193 字 |
| 6 年 | 191 字 |
| 合計 | 1,026 字 |

- 出題範囲は現行学習指導要領の学年別漢字配当表、読みは常用漢字表の音訓のうち小学校で扱うもの
- 1 漢字の各読みにつき、3 形式のいずれかで最低 1 問以上の問題を用意する
- 問題データ 1 件の項目(例): 問題 ID、学年、単元、出題漢字、形式、問題文、正解の読み、誤答 3 件、音訓区分
- 自社で作成(生成 AI 活用 + 人手チェック)し、全件チェックしたもののみ収録する

## 非機能要件

| ID | カテゴリ | 非機能要件 | 対応要求 |
| --- | --- | --- | --- |
| NFR-001 | 性能 | 選択肢タップから正誤表示まで 0.1 秒以内(通信を伴わない端末内処理) | REQ-004 |
| NFR-002 | 性能 | 初回読み込みはモバイル回線(4G 相当)で 5 秒以内に学年選択画面を表示 | REQ-013, REQ-015 |
| NFR-003 | 可用性 | 初回読み込み後は通信なしで学習機能が動作する。配信サーバー停止時も既存利用者の学習は継続できる | REQ-014 |
| NFR-004 | 互換性 | 対応環境: iPadOS / iOS の Safari、Android / ChromeOS / Windows の Chrome・Edge、いずれも最新 2 メジャーバージョン | REQ-015 |
| NFR-005 | ユーザビリティ | タブレット・スマートフォン・PC の画面サイズと縦横の向きに対応する。タップ領域は 1 辺 44pt 以上 | REQ-003, REQ-015 |
| NFR-006 | ユーザビリティ | アプリ起動から 3 タップ以内で出題を開始できる。回答は 1 タップで完結する | REQ-003, REQ-004 |
| NFR-007 | ユーザビリティ | 画面の文言はひらがな中心(低学年が読める表記)とし、文字サイズは小学 1 年生が読める大きさとする | REQ-016 |
| NFR-008 | アクセシビリティ | 正誤表示は色だけに依存せず記号を併用する。音声 OFF でも学習が成立する | REQ-006, REQ-016 |
| NFR-009 | セキュリティ | 通信は TLS 1.2 以上で暗号化する | REQ-013 |
| NFR-010 | プライバシー | 氏名・メールアドレス等の個人情報を収集しない。ニックネーム・学習履歴を含め、学習に関するデータを端末外へ送信しない | REQ-013 |
| NFR-011 | 規模 | 想定利用者数はリリース後 1 年で 1,000 人程度。配信は静的ファイル中心とし、利用者増加時もサーバー増強を要しない構成とする | REQ-013, REQ-014 |
| NFR-012 | データ品質 | 問題データの読みの誤りは、リリース時点で既知の誤り 0 件とする。全件を人手でチェックする | REQ-002 |
| NFR-013 | 運用・保守 | 問題データはアプリ本体のコードと分離し、データ修正のみで再リリースできる | REQ-002 |
| NFR-014 | データ保持 | 端末内データが失われる条件(ブラウザデータ削除、一部ブラウザでの一定期間未使用時の自動削除等)を利用者に案内し、ホーム画面への追加を推奨する | REQ-013, REQ-014 |
| NFR-015 | ライセンス | 利用する素材・フォント・ライブラリのライセンス条件を満たす。読み上げ音声(VOICEVOX)のクレジットとフォントのライセンス表記をアプリ内に表示する | REQ-006 |

## 用語定義

| 用語 | 定義 |
| --- | --- |
| 学年別漢字配当表 | 学習指導要領で定められた、小学校の各学年で習う漢字の一覧(計 1,026 字) |
| 音読み / 訓読み | 漢字の中国由来の読み / 日本語の意味に当てた読み。本アプリでは選択肢をすべてひらがなで表記する |
| 出題形式 | 単漢字の読み・熟語の読み・文中の読みの 3 種類 |
| セット | 1 回の学習で連続して解く固定数の問題のまとまり |
| 単元(ステージ) | 学年内の漢字を一定数ずつ区切った学習単位 |
| ふつうモード | 単元を選んで 1 セットを解く通常の学習モード |
| タイムアタック | 時間を競う学習モード |
| ふくしゅうモード | 過去に間違えた問題のみを出題するモード |
| 習得済み | 漢字ごとに定めた正解条件を満たした状態 |
| プロフィール | 1 端末内で学習者を区別するための情報(ニックネーム・アイコンのみ) |
