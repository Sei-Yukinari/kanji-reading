ユーザーの活動(バックボーン)を時系列に並べ、その下にユーザーストーリーを配置してリリース単位に分割します。MVP のスコープ決定と[見積もり](/estimate)のフェーズ分けの根拠になります。

## ストーリーマップ

```mermaid
flowchart LR

    subgraph A3["例: 在庫を確認する"]
        direction TB
        A3M["MVP: 在庫数を一覧で見られる"] --> A3R["R2: 在庫金額を集計できる"] --> A3F["将来: 発注点アラートが届く"]
    end
    subgraph A4["例: 棚卸しする"]
        direction TB
        A4M["MVP: 実在庫を入力して差異を見られる"] --> A4R["R2: 結果を PDF 出力できる"]
    end
    A1 --> A2 --> A3 --> A4
```
