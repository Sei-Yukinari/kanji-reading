## 背景

- 小学校では学年ごとに習う漢字が「学年別漢字配当表」で定められており、6 年間で計 1,026 字を習う
- 漢字の読みの練習は、紙のドリルや書き取りが中心になりやすく、1 問ごとの手間が大きいため反復回数を稼ぎにくい
- 子どもが自分でテンポよく取り組める、操作が簡単な読み練習の手段が求められている

## 目的

- 小学 1〜6 年生が、自分の学年で習う漢字の読みを、選択式でテンポよく繰り返し練習できる Web アプリを提供する
- 学年別漢字配当表の全 1,026 字を網羅し、各学年で習う読みをすべて練習できる状態にする

## プロダクト概要

| 項目 | 内容 |
| --- | --- |
| 対象ユーザー | 小学 1〜6 年生(家庭学習) |
| 提供形態 | Web アプリ(PWA)。タブレット・スマートフォン・PC/Chromebook のブラウザで動作 |
| 料金 | 無料(収益化は今回対象外) |
| アカウント | 不要。学習履歴は端末内に保存。1 端末で複数の学習者プロフィールを切替可能 |
| 出題形式 | 4 択。熟語の読み・文中の読みの 2 形式 |
| 出題範囲 | 学年別漢字配当表 1,026 字、学習指導要領で小学校で扱う読み |

## スコープ

### 対象範囲

- 学習アプリ(PWA)の開発
  - 学年・単元選択、4 択出題(2 形式)、正誤判定、結果表示
  - 効果音・音声読み上げ、タイムアタック、メダル・スタンプ
  - 間違えた問題の復習、漢字ごとの習得状況表示
  - 学習者プロフィール(ニックネームのみ)の作成・切替
  - 端末内への学習履歴保存、オフライン動作
- 問題データの作成(全 1,026 字分の読み・熟語・例文・誤答選択肢)
  - 自社で作成(生成 AI 活用 + 人手チェック)
- ホスティング環境の構築・リリース

### 対象外

- 漢字の書き取り・書き順の練習
- 保護者向け機能(学習状況の閲覧・管理画面など)
- 学校・教室向け機能(教員による児童管理など)
- ユーザーアカウント登録・ログイン・端末間の学習履歴同期
- 課金・広告
- 利用統計(アクセス解析)の収集
- ネイティブアプリ(iOS / Android)の開発・ストア配信
- 中学校以降で習う漢字・読みの出題
- 外部有識者(教員等)による問題データの監修

## 前提条件・制約

- 納期: 開発開始から 3 ヶ月以内にリリースする
- 問題データは自社で作成し、読みの正確性は自社で全件チェックする(外部監修なし)
- 出題範囲は現行学習指導要領(2020 年度施行)の学年別漢字配当表に準拠する
- 学習履歴は端末内のみに保存するため、ブラウザのデータ削除・端末変更で履歴は失われる
- 想定利用者数はリリース後 1 年で 1,000 人程度
